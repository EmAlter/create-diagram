# Create Diagram
**Create Diagram** is a Minecraft addon which provides you with a full in-game flowchart editor, perfectly integrated with the mechanics, recipes, and graphics of the Create mod (by the Create Team) and all its add-ons (e.g., Create: New Age).

**Mod Loader:** NeoForge (1.21.1)

**Required Dependencies:**
- [EMI](https://modrinth.com/mod/emi) — Essential for recipe resolution, tooltips, and GUI rendering.
- [JEI](https://modrinth.com/mod/jei) — Used by EMI as a "backend".
